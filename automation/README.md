# LOOKIQ Omnichannel Product & Social Automation Engine

An autonomous, 1-click cross-platform publishing engine for LOOKIQ.

---

## 1. How It Works (The Complete Flow)

Whenever you send an Amazon product link (e.g. `https://amzn.to/...` or `https://www.amazon.com/dp/...`) via Telegram or CLI:
1. **Metadata & Affiliate Attribution:** Resolves the short link, extracts ASIN, ensures `tag=likeefashionh-20`.
2. **Product Page Creation:** Generates an SEO-optimized, mobile-ready PDP at `products/{slug}.html` with Google Schema JSON-LD and sticky buy bar.
3. **2:3 Pinterest Pin Generation:** Downloads the image and converts it into a high-definition 2:3 vertical aspect ratio (`1000 x 1500 px`) pin in `assets/pins/{slug}-pin.jpg`.
4. **Pinterest RSS Injection:** Injects the item into `feed.xml` with media enclosure tags for zero-click auto-publishing on Pinterest.
5. **Git Auto-Push:** Commits and pushes changes directly to GitHub so GitHub Pages deploys the live product immediately.
6. **Multi-Platform Social Syndication:** Generates ready-to-publish copy for:
   - **Pinterest:** Guided Search SEO Title, Alt Text, and Search Intent Description.
   - **Instagram:** Quiet Luxury Hook, pricing, rating, and bio link CTA.
   - **Facebook Page:** Engaging shopping post with direct LookiQ page link.
   - **TikTok:** Photo Mode caption and viral fashion hashtags.

## 2. Quick Setup: Telegram Bot (In 1 Minute)

1. Open Telegram on your phone or PC and search for `@BotFather`.
2. Send `/newbot` and follow the prompts to choose a name (e.g. `LookIQ Publisher Bot`) and username (e.g. `lookiq_publisher_bot`).
3. BotFather will provide an API Token (e.g. `7890123456:AAH...`).
4. Paste your token into `automation/config.json`:
   ```json
   {
     "affiliate_tag": "likeefashionh-20",
     "telegram_bot_token": "YOUR_TOKEN_HERE"
   }
   ```
5. Start the bot on your computer:
   ```bash
   python automation/telegram_bot.py
   ```
6. Open your bot on Telegram, send `/start`, and then simply send any Amazon link!

---

## 3. Running from Command Line (Without Telegram)

You can run the pipeline directly on your computer at any time:
```bash
python automation/run_local.py "https://amzn.to/your-link"
```

## 4. Connecting Cross-Platform Auto-Posting

### Pinterest (Zero Maintenance via RSS)
1. Go to your Pinterest Business account -> Settings -> Claimed Accounts.
2. Ensure your website (`lookiq.github.io` or custom `.com`) is claimed.
3. Go to **Bulk create Pins** -> **Auto-publish from RSS feed**.
4. Enter your feed URL: `https://lookiq.github.io/feed.xml`.
5. Select the board where new pins should land.
6. Pinterest will now automatically publish pins as soon as `feed.xml` updates!

### Instagram & Facebook Page (Auto-Sync)
1. In Meta Business Suite, connect your **Instagram Professional Account** to your **Facebook Page**.
2. Enable "Automatically share Instagram posts to Facebook Page".
3. When posting to Instagram (or via the captions generated by the bot), it automatically posts to Facebook Page simultaneously.

### Full Webhook Automation (Optional)
If you use a tool like **Make.com**, **Metricool**, or **Buffer**:
1. Get your webhook URL.
2. Put it in `automation/config.json` under `"webhook_url"`.
3. The pipeline will automatically POST the complete multi-platform payload upon product generation.
